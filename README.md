# Konrad Trestka — Personal Website

Next.js + Chakra UI.

## Project Structure

```text
/
├── public/           static assets (favicons, logos, résumé PDF)
├── components/       shared UI (Navigation, Footer, MyHeading, MountainBackdrop)
├── pages/            routes — index.js, work.js, contact.js
└── package.json
```

## Commands

| Command      | Action                                  |
| :----------- | :--------------------------------------- |
| `yarn`       | Install dependencies                     |
| `yarn dev`   | Start local dev server at `localhost:3000` |
| `yarn build` | Build the production site                |
| `yarn start` | Run the production build                 |
